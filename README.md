A modern full-stack Kanban board application built with Next.js 16, React 19, and PostgreSQL for efficient task management. Features drag-and-drop cards between lists, priority levels with color coding, and status tracking for workflow visualization. Includes secure authentication with NextAuth.js, dark mode support, and a responsive design that works on all devices. Perfect for organizing personal projects or team workflows with an intuitive, clean interface.
